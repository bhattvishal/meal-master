# meal-master

Meal Master is a meal-planning project. The goal is to help you plan your meals, organize recipes, and build grocery lists.

> **Status:** Early stage. The repository has no application code yet, so this README will change as the project grows.

## Planned features

- **Meal planning:** plan breakfast, lunch, and dinner for the week.
- **Recipe management:** save, browse, and edit your recipes.
- **Grocery lists:** build a shopping list from your meal plan.
- **Nutrition overview:** see a summary of nutrition for the meals you plan.

## Getting started

Clone the repository:

```bash
git clone https://github.com/bhattvishal/meal-master.git
cd meal-master
```

Setup, build, and run instructions will be added here once the tech stack is chosen.
